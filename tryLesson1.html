Lesson 1: Try/Catch Statement

An exception is an error that occurs that will crash the program. An example is putting a character when the variable is asking for an integer. We know that some inputs can cause a piece of code to crash and to avoid that we can use a try catch block. You can put the code that can cause a crash in the try block, and if an exception occurs, the catch block will “catch it” and execute its code.

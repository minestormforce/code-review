Lesson 1: Nested If Statements and Error Checking

Have you ever heard of matryoshka dolls? They are similar in a way to nested if statements. In order to reach the inside doll, you have to open up the outside ones first. This is just like nested if statements where you must meet the condition of the parent statement before getting to the nested statement.

Something else you can do with if statements is error checking. You have probably been declaring variables as “int” and asking for user input for a while now, but what if the user inputs a decimal number, or even a character. Your program will end up crashing. To fix this, you can implement error checking. In this scenario, you can use “if (console.hasNextInt()) {}” to check if the user enters an integer, and then if they don’t you can apply an else statement. It is always advised to add error checking to your code. Keep in mind, there is no hasNextChar().

Method Descprition
hasNext() Checks if something was typed.
hasNextBoolean() Checks if true or false was typed.
hasNextByte() Checks for a byte (re-visit variables unit)
hasNextShort() Checks for a short.
hasNextInt() Checks for an integer.
hasNextLong() Checks for a long.
hasNextFloat() Checks for a float.
hastNextDouble() Checks for a double.

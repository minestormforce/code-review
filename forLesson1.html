Lesson 1: For Loop

We learned the while loop, now we are going to learn the for loop. All loops have three parts to it: initialization, condition that stops the loop, and code that modifies the condition and stops the loop. For loops are convenient because you could put all three of them together on the same line. For loops are also convenient when you want code to repeat a specified number of times. You can view the syntax for it below.

Conventionally, you would use variables i, j, and k in for loops. It is also important to make sure your code works, because if you input the operators or numbers incorrectly, your code may loop forever or may never run at all. And remember, you can use the break statement and you can nest for loops as well.

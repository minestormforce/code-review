Lesson 2: If Statement

Now its time to learn about the if statement. The if statement is used to make a comparison with a variable with either a value or another variable. This uses the logical expressions we learned in the previous lesson. If the condition is true, then the code in the if statement is run.

But what if we want to execute something when the condition is false? Then we add en else statement that code will print out if the condition is false! But now let’s say you want to add more conditions, then you would add an else if statement, and you are able to add as many as you want!

You are also able to make it ask for two statements to be met first, or one of two, or even three statements to be met by using logical operators like AND (&&) and OR (||). Not only that, but you are also able to compare characters as well, however, you are not able to compare strings with logical operators, but rather methods.

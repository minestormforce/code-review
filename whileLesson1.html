Lesson 1: Nested If Statements and Error Checking

What’s up guys, this time we’re going to learn about loops. A loop is a chunk of code that is repeated. There are different ways of looping in Java, but in this lesson, we’re going to cover the while loop and the do-while loop. A while loop will check if a condition is true and will continue looping until that condition is false. We use the while loop when we don’t know how many times we want the code to be run. So technically it could end up not running at all!

When you want to exit the loop, you may use the break statement. This can be used to prevent infinite loops, among other things. You can view the syntax of a while loop below.

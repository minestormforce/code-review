Lesson 1: Declaring and Initializing Variables

You can think of a variable as a box. A box can hold and store an object. This is what a variable does. It can hold and store a value. However, it cannot be just any value, it must be a value that aligns with the variable's datatype. You can think of a datatype as a categorization for the boxes. Each box can only contain one specific type of object, like books. Each variable will only be able to contain one type of value, for example an "int" variable will contain only integers.

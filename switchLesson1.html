Lesson 1: Switch Statement

You may be familiar with using an insane amount of if-else statements when there are many different cases to account for. Luckily for you, there is a better way to perform the same task… using the switch statement. You can specify what will happen depending on certain cases. You can also input a default case that will execute if none of the above conditions were met. You can view the syntax below.

However, there are some limitations to the switch statement. Only one variable can be tested at a time and it only works with some primitive data types (byte, short, char, int) unless your on Java 7 and above. Now good luck with your next exercise!

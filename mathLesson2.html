Lesson 2: Special Operators and Casting

There are also special operators inside Java, allowing you to combine the uses of the equal sign and basic operators. For example, “a += 5;” would set the variable ‘a’ to the value of ‘a + 5.’ There are also increment and decrement operators, using the double plus and double minus respectively. This will cause the value to increase or decrease by one.

Operator Example Equivalent
+= Plus Equals a += 6; a = a + 6;
-= Minus Equals a -= 7; a = a - 7;
*= Times Equals b *= 6; b = b * 6;
/= Divide Equals b /= 7; b = b / 7;
%= Mod Equals b %= 6; b = b % 6
++ Increment c ++; c = c + 1;
-- Decrement c --; c = c - 1;

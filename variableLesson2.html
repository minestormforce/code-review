Lesson 2: Primitive Datatypes, Strings, Conventions

What’s up guys! You know that each box, or variable, can only contain one type of item. That is a data type. In Java, there are 8 primitive data types of variables, plus strings. Each data type will have its own use and contain its own item. You can view them in the chart below!

Datatype Descprition Examples
int Stores integers from -2^31 to 2^31 - 1 with four bytes. int a = 5;
byte Stores integers from -128 to 127 with one byte. byte a = -3;
short Stores integers -32,768 to 32767 with two bytes. short a = -300;
long Stores integers from -263 to 263 - 1 with eight bytes. long a = 67;
float Stores decmial numbers with four bytes and must end with 'f' or 'F'. float a = 3.14f;
double Stores decimal numbers with eight bytes. double a = 6.7676767;
char Stores one 16-bit unicode character and the value must be closed with single quotations. char a = 'a';
boolean Stores a value of either true or false. boolean a = true;

To store multiple characters, you may use a string. They are technically not datatypes, but objects. However, Java let's you treat them as datatypes. But remember, when declaring a string, you must capitalize the 's' and use double quotations marks for the value.

Remember to name your variables properly and as descriptive as possible. Convention is to use camel case, where you omit the spaces and don't capitalize anything except for the starting letter of the second, third, fourth,... words.
